# Support

`agent-search-gateway` is community-maintained alpha software. Support is provided on a best-effort basis with no guaranteed response or resolution time.

## Where to ask

- Read the [README](README.md), especially the configuration, command, and `doctor` sections.
- Review the [public interface and compatibility policy](docs/public-interface.md).
- Search existing issues before opening a new one.
- Open a GitHub issue for a reproducible project bug, documentation problem, or focused feature request.

For help requests, include the project version or commit, operating system, Python and uv versions, the exact command, expected and observed behavior, and a minimal redacted configuration. Use `agent-search-gateway doctor` and include only output that has been reviewed for sensitive data.

## Boundaries

The maintainers cannot troubleshoot provider account status, billing, quotas, private network policies, or third-party service outages. Contact the relevant provider for those issues.

Do not post API keys, signed URLs, private prompts, customer data, full debug logs, or proprietary page content. Replace secrets and sensitive values with explicit placeholders before sharing.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not be reported in a public support issue.
